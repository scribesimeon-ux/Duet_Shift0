# Challenge requirements

Source: the user-provided Stage 1 project brief. This summarizes the supplied challenge constraints; it is not an independently verified copy of official rules. No additional official requirements are asserted.

- Online, simulation-first challenge.
- Two simulated SO-101 arms.
- MuJoCo as the primary simulator.
- Natural-language instructions.
- Camera and multimodal observations.
- Bimanual manipulation.
- A multi-step table-setting workflow.
- Robustness under randomized conditions.
- Robotics policy training or fine-tuning.
- OpenVINO optimization.
- Final deployment on Intel Core Ultra Series 2/3.
- A reproducible GitHub repository.
- An Intel benchmark script.
- Evaluation/demo across 10 randomized seeds.
- Technical architecture documentation.

Stage 1 only records these constraints. It provides no simulator, robot assets, policy, benchmark, evaluation, or evidence of challenge performance.

DuetShift's planned change detection, selective replanning, human goal revision, dynamic arm reassignment, and useful handoffs are project design goals. Optional Speechmatics voice input is also a project plan; it is not asserted here as an official challenge requirement.
